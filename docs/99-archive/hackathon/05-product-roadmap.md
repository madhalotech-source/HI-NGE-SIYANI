# Product Roadmap

Every item below is either **Working (MVP)**, **In Progress**, or **Coming Soon**. Nothing marked Coming Soon is claimed as built.

## Phase 1 — MVP (Hackathon Build)

**Status: Working / In Progress**

- [x] Language selection (English, isiZulu, Sepedi, Tshivenda, Xitsonga)
- [x] Onboarding: name, age, province, current status
- [x] Multi-select life-area focus (Education, Government Services)
- [x] Education guidance: bursary matching, TVET/university pathways, career direction
- [x] Government Services guidance: funding guidance, business registration walkthroughs
- [x] Confidence-check fallback for lower-resource languages
- [ ] Optional Reminder Centre (basic reminders) — **In Progress**

## Phase 2 — Expansion — **Coming Soon**

- Finance vertical: budgeting, savings planning, investment education
- Healthcare Information vertical: service directories, plain-language guidance
- Full Reminder Centre: bursary deadlines, application windows, compliance dates, medical appointments
- Flutter cross-platform rebuild (iOS parity)
- Expansion to additional official languages beyond the initial five

## Phase 3 — Platform — **Coming Soon**

- Employment vertical: job-matching guidance, CV support
- Entrepreneurship Support vertical: funding directories, compliance guidance
- Community Opportunities vertical
- Full 11 official South African languages
- Web platform
- Government/NGO partner integrations (formal API partnerships)

## What We Will Not Promise

We will not claim voice interaction, full government system integrations, or all eleven languages are live until they demonstrably are. Judges and users should be able to trust every "Working" label in this document.
